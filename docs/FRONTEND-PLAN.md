# پلن فرانت (همزمان با بک‌اند)

## اصول
- UI فقط نمایش و فراخوانی API است؛ منطق کسب‌وکار در هاست/Core است.
- هر ویژگی اختیاری فقط وقتی نشان داده می‌شود که هاست (Edition و Permission) جواب بدهد.
- هر فاز بک‌اند، همان فاز فرانت: بک‌اند اول، بعد صفحه‌اش؛ هر دو در پایان فاز تحویل می‌شوند.
- UI از صفر ساخته می‌شود؛ TMPBUI فقط برای ایده.

## استک
React 19 + TypeScript + Vite + Tailwind 4، RTL فارسی (Vazirmatn)، SignalR برای اعلان/چت، نمودار با Recharts، آیکن lucide.
قرارداد API: از Swagger هاست، تایپ‌ها با openapi-typescript تولید می‌شود (دست‌نویس نمی‌شود).
خطای ۴۰۹ (RowVersion): بارگذاری دوباره + پیام «توسط دیگری تغییر کرد».

## ساختار
src/api (کلاینت و تایپ‌های تولیدی) · src/auth · src/features/<ماژول> · src/shell (منو، هدر، قابلیت‌ها) · src/ui (دکمه، جدول، مودال)
